Grid and layout

Asymmetric layout example with label and content columns.

METADATA

Asymmetric balance

The default page composition uses asymmetric grid placement. Navigation elements align left at fixed width; primary content offsets right. Tension comes from grid structure, not centered alignment.

Centered compositions are reserved for the radar canvas itself, modal overlays, and empty states. All measurements align to the 4px baseline grid.
